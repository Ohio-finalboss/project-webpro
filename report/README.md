# รายงานระบบ Flower Shop

เอกสารในโฟลเดอร์นี้จัดทำจากซอร์สปัจจุบันใน `flower2` ครอบคลุมไฟล์ `.js`, `.ejs`, `.css` และ `.html` ที่เกี่ยวกับการทำงานของระบบ โดยแยกตามขอบเขตงานดังนี้

- `emp/`: ระบบพนักงานร้านดอกไม้ รวมหน้าแดชบอร์ด คิวงาน การจัดช่อ การยืนยันชำระเงิน การส่งมอบ ใบเสร็จ และการอัปเดตแบบ SSE
- `bouquet-make/`: หน้าแรกของลูกค้าและระบบออกแบบช่อ จบที่การเพิ่มช่อลงตะกร้า
- `status-order/`: การค้นหาและแสดงสถานะคำสั่งซื้อ
- `cart/`: ตะกร้า ข้อมูลติดต่อ/การรับสินค้า ตรวจสอบคำสั่งซื้อ และชำระเงิน
- `partial/`: EJS partial และรูปแบบที่ใช้ซ้ำ เช่น แถบนำทางลูกค้าและฟอนต์

แต่ละไฟล์รายงานมีลำดับขั้นตอน รายชื่อไฟล์ และส่วนอธิบายโค้ดแยกตามไฟล์/ช่วงบรรทัด โดยแจกแจงหน้าที่ของคำสั่ง JavaScript, EJS, HTML และคุณสมบัติ CSS พร้อมภาคผนวกซอร์สเต็มเพื่อเทียบกับคำอธิบายได้ครบทุกบรรทัด

ข้อยกเว้น: ไม่นำ `db/`, `node_modules/`, ไฟล์ฐานข้อมูล, dependency และไฟล์รูปภาพ/สื่อมาใส่ในรายงาน ตามขอบเขตที่กำหนด

> เส้นทางและลำดับการทำงานอ้างอิงจากโค้ดใน `flower2` ณ วันที่จัดทำเอกสาร หากแก้โค้ดภายหลัง ควรปรับรายงานส่วนที่เกี่ยวข้องให้ตรงกับซอร์สล่าสุด
