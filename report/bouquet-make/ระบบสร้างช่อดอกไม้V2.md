# ระบบสร้างช่อดอกไม้ - Technical & Architecture Report

## 1. ภาพรวมสถาปัตยกรรมและเทคโนโลยีที่ใช้ (Architecture & Tech Stack)

ระบบแบ่งเป็น UI Layer (EJS/CSS/Browser JavaScript), Business Logic Layer (Express routes/helpers), Data Layer (SQLite ผ่าน prepared statements) และ External Services ที่โหลดฟอนต์ Prompt จาก Google Fonts; SSE ใช้อัปเดตหน้าเว็บแบบ one-way โดยไม่ต้อง polling.

- **UI Layer:** EJS สร้าง HTML จากข้อมูลที่ server ส่ง; CSS จัดธีม/การแสดงผล; JavaScript ฝั่ง browser จัดการ event, pagination และ live refresh.
- **Business Logic Layer:** Express routes ตรวจค่าจาก request, ควบคุมสถานะคำสั่งซื้อ/ตะกร้า/การชำระ และเลือก view หรือ response.
- **Data Layer:** SQLite เก็บลูกค้า คำสั่งซื้อ รายการช่อ การชำระ และพนักงาน; ใช้ prepared statements ใน server/routes.
- **Tools:** Node.js รัน server; Express จัด HTTP routes/middleware; EJS เลือกเพราะ server สร้าง HTML พร้อมข้อมูลได้โดยตรง; SQLite เหมาะกับฐานข้อมูลไฟล์ในแอปนี้; express-session เก็บ state ของลูกค้าข้ามหน้า; SSE ส่ง event ทางเดียวให้หน้าที่เปิดอยู่โดยไม่ polling; CSS/vanilla JavaScript จัด UI โดยไม่เพิ่ม client framework.

### ลำดับการทำงานและกฎธุรกิจ



1. `GET /` แสดง `customer-home.ejs`; ปุ่มสั่งทำช่อเปิด `/shop`
2. `GET /shop` เรียก `loadCatalog()` อ่านรายการ `items` และ `bouquet_templates` แล้ว `render()` ส่งข้อมูลเริ่มต้นให้ `shop.ejs`
3. JavaScript ใน `shop.ejs` เตรียม state สำหรับขนาด เทมเพลต ดอกไม้ กระดาษ ของตกแต่ง การ์ด และจำนวนช่อ จากนั้นวาด stepper, panel และภาพ preview
4. ลูกค้าเลือก 3 ขั้นตอน: รูปแบบ/ขนาด → ดอกไม้ → วัสดุ/ของตกแต่ง; preview SVG เปลี่ยนตาม state
5. เมื่อกดเพิ่มสินค้า browser ส่ง payload ไป `POST /cart/add`; server เรียก `build()` ตรวจขนาด จำนวน สต็อก ส่วนประกอบ เทมเพลต และค่าราคาใหม่จาก DB
6. server สร้าง `bouquet_ID`, บันทึก `bouquets`, `bouquet_items`, `cart_items` ภายใน transaction แล้วตอบ JSON `{ ok, redirect }`; browser ไป `/cart`
7. การแก้ช่อในตะกร้าใช้ `GET /bouquet/edit/:id` โหลดข้อมูลเดิมเป็น initial state แล้ว `POST /bouquet/update/:id` เขียนรายละเอียดช่อใหม่ โดยตรวจว่าเป็นช่อใน cart/session ของผู้ใช้

## หน้าที่ของฟังก์ชันและ code sections

### 1. ค่าคงที่และ helper ของ `routes/shop-builder.js`

- `MAX_STEMS`, `PAPER_QTY`, `DECOR_MAX`, `MAX_QTY`, `SERVICE_FEES`: ข้อจำกัดดอกไม้/กระดาษ/ของตกแต่ง จำนวนช่อสูงสุด และค่าบริการตามไซส์ S/M/L
- `today()`: สร้างวันที่รูปแบบ `YYYYMMDD`
- `rid(prefix, table, column)`: สุ่ม byte 4 ตัวเป็นเลขฐาน 16 ตัวพิมพ์ใหญ่ สร้าง ID รูปแบบ prefix-date-random และตรวจซ้ำในคอลัมน์
- `kindOf(item)`: จัดชนิด item เป็น flower, paper, card หรือ decor จาก ID/ประเภทสินค้า
- `getCartId(req, create)`: อ่าน UUID ตะกร้าจาก session; ถ้าไม่มีและอนุญาตให้สร้าง ใช้ `crypto.randomUUID()` แล้วเขียนตาราง cart
- `cartCount(req)`: รวมจำนวนช่อใน `cart_items` ของ cart ปัจจุบัน
- `loadCatalog()`: อ่าน items และ template_items; สร้าง model สินค้าและเทมเพลตให้ frontend
- `render(req, res, initial, editId)`: เตรียม boot data ส่ง `items`, `templates`, limits, serviceFees, จำนวนตะกร้า และข้อมูลแก้ไขให้ EJS

### 2. `build(body)` ตรวจและคำนวณช่อฝั่ง server

1. ยืนยัน size อยู่ใน S/M/L และจำนวนช่อ 1 ถึง `MAX_QTY`
2. สร้าง Map จากสินค้าในฐานข้อมูล แล้วรวมรายการซ้ำใน `body.items`
3. แยกจำนวน stems/paper/card/decor; กำหนดจำนวนกระดาษตามไซส์และตรวจเพดานของตกแต่ง
4. ตรวจ stock, ต้องมีดอกไม้อย่างน้อย 1 ก้าน, ไม่เกินจำนวนตามขนาด, เลือกกระดาษหนึ่งแบบ และการ์ดไม่เกินหนึ่งใบ
5. คำนวณราคาจาก `item_unit_price` ในฐานข้อมูล ไม่เชื่อราคาจาก browser
6. บวก `SERVICE_FEES[size]`; เก็บข้อความการ์ด/หมายเหตุ/ชื่อช่อตามความยาวที่กำหนด
7. ตรวจว่ารายการตรงกับ `template_items` ทั้งชุดก่อนบันทึก `template_ID`
8. ส่งกลับ `{ size, qty, rows, unit, serviceFee, cardMessage, note, name, templateId }`

### 3. การเขียนข้อมูลและ routes ของ shop builder

- `writeItems(bouquetId, rows)`: ลบส่วนประกอบช่อเดิมแล้ว insert รายการใหม่ใน `bouquet_items`
- `GET /`: route แสดง customer home; หากมี query `order_id`/`role` จะ redirect ตามหน้าสถานะ/พนักงาน
- `GET /shop`: render หน้าสร้างช่อและแคตตาล็อก
- `POST /cart/add`: สร้างช่อ/ส่วนประกอบ/cart item ภายใน `db.transaction`; ส่ง JSON ผลลัพธ์ให้ frontend
- `GET /bouquet/edit/:id`: ตรวจ ownership ผ่าน cart_ID, โหลด bouquet/components เป็น initial state
- `POST /bouquet/update/:id`: ตรวจ ownership, เรียก build, transaction อัปเดต bouquets, bouquet_items และ cart quantity/price

### 4. `views/shop.ejs`: template, styles, state และการวาดผล

- ส่วน `<head>` และ `<style>` กำหนด Prompt, สีพื้นหลัง, header, stepper, cards, swatches, panel, preview, summary, toast และ media queries
- ตัวแปร EJS `boot` ถูกแปลงเป็นข้อมูล JavaScript `items`, `templates`, limits, `serviceFees`, `initial`, `editId`; `cartCount` แสดงจำนวนช่อในเมนู
- Helper ฝั่ง browser เช่น `$`, `money`, `esc`, `toast`, `colorOf`, `shade`, `shortType`, `tplFor`, `applyTemplate`, `stems`, `lines`, `unit`, `missing` จัดการ DOM, escape HTML, สี/ราคา และข้อกำหนดการเลือก
- `petals()`, `flower()`, `thumb()`, `bouquetSVG()` สร้าง SVG preview จากรายการที่เลือก; แยกทรงกุหลาบ ทานตะวัน เดซี่ ลิลลี่ คาลล่าลิลลี่ ทิวลิป ไฮเดรนเยียและดอก filler รวมกระดาษ ริบบิ้น โบว์ ผีเสื้อ และการ์ด
- `renderSteps()`, `stepper()`, `swatch()`, `panel1()`, `panel2()`, `panel3()` สร้าง UI แต่ละขั้น; panel1 เป็นรูปแบบ/ขนาด, panel2 เป็นดอกไม้, panel3 เป็นวัสดุ/ของตกแต่ง/การ์ด/ข้อมูลเพิ่มเติม
- `renderPanel()`, `renderPreview()`, `renderAll()` นำ state ไปวาด step navigation, panel, SVG preview และสรุปราคารวมค่าจัด/จำนวนช่อ
- `document.addEventListener('click', ...)` ใช้ `data-a` ระบุ action เช่น go/size/template/category/step/paper/decor/card/quantity และเรียก render ใหม่
- input listeners เก็บข้อความการ์ด/ชื่อ/หมายเหตุ; submit handler ป้องกันส่งซ้ำ สร้าง JSON payload POST ไป `/cart/add` หรือ `/bouquet/update/:id`, แสดง error ผ่าน toast/msg และ redirect เมื่อสำเร็จ

### 5. หน้าแรก `views/customer-home.ejs`

ประกอบด้วยหน้า hero FlowerShop, ข้อความแนะนำ, ปุ่มสั่งทำช่อที่เชื่อม `/shop`, SVG ดอกไม้ตกแต่ง และ CSS responsive/animation ในไฟล์เดียว ไม่มีการสร้าง order หรือเขียนฐานข้อมูลในหน้านี้

**Component-by-component explanation:**

- `<head>` — กำหนดชื่อหน้า, meta, ฟอนต์, stylesheet และ script ที่หน้าใช้งาน; ไม่ใช่เนื้อหาหลักที่ผู้ใช้เห็น.
- `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` (ตามที่มี) — แบ่งหน้าเป็นส่วนหัว/นำทาง/เนื้อหาหลัก/ส่วนย่อย/ท้ายหน้า เพื่อจัด layout และลำดับเนื้อหา.
- `<% if/else %>` เลือกเนื้อหาตามข้อมูลจริง เช่น error, empty state หรือสถานะคำสั่งซื้อ; `<% array.forEach(...) %>` สร้างแถว/รายการซ้ำตามจำนวนข้อมูล; `<%= value %>` แสดงข้อมูลแบบ escape; `<%- include(...) %>` แทรก partial HTML ที่ใช้ร่วมกัน.
- `name="viewport"` — บอก browser ให้ปรับขนาดหน้าให้พอดีกับความกว้างอุปกรณ์ จึงช่วยให้ layout แสดงผลเหมาะกับมือถือ.
- `name="theme-color"` — ระบุชื่อ field ที่ส่งกับฟอร์มหรือข้อมูลที่ JavaScript อ่าน.
- `href="https://fonts.googleapis.com"` — เชื่อมต่อบริการฟอนต์ของ Google เพื่อโหลดแบบอักษรที่หน้าเว็บใช้.
- `href="https://fonts.gstatic.com"` — เตรียมการเชื่อมต่อกับ host ที่ส่งไฟล์ฟอนต์ ช่วยให้ browser โหลดฟอนต์ได้เร็วขึ้น.
- `href="https://fonts.googleapis.com/css2?family=Prompt:wght@300;400;500;600&display=swap"` — ให้ browser โหลดฟอนต์ Prompt ที่ใช้แสดงข้อความบนหน้านี้.
- `href="/shop"` — กำหนดปลายทางที่เปิดเมื่อผู้ใช้คลิกลิงก์.

````javascript
// routes/shop.js  — หน้าสั่งทำช่อดอกไม้ (use case: สั่งทำช่อดอกไม้)
// สมมติฐาน: ใช้ better-sqlite3 + express-session  (ถ้าใช้ sqlite3 แบบ callback ต้องปรับส่วนเรียก db)
//
// ใน server.js:
//   const shopRoutes = require('./routes/shop');
//   app.use(shopRoutes(db));        // db = new Database('flowershop1 (1).db')
//
// เส้นทางที่เพิ่ม:  GET /shop · POST /cart/add · GET /bouquet/edit/:id · POST /bouquet/update/:id

const express = require('express');
const crypto = require('node:crypto');

const MAX_STEMS  = { S: 8, M: 20, L: 40 };   // จำนวนก้านดอกไม้สูงสุดต่อขนาด (ปรับได้)
const PAPER_QTY  = { S: 1, M: 2, L: 3 };     // จำนวนแผ่นกระดาษห่อต่อขนาด (ตามเทมเพลตของร้าน)
const DECOR_MAX  = { 'ริบบิ้น': 3, 'โบว์': 3, 'ผีเสื้อ': 6 };
const MAX_QTY    = 10;                       // จำนวนช่อต่อรายการ
const SERVICE_FEES = { S: 100, M: 200, L: 350 };

module.exports = function (db) {
  const router = express.Router();
  router.use(express.json());

  /* ---------- helpers ---------- */
  const today = () => {
    const date = new Date();
    const pad = (value) => String(value).padStart(2, '0');
    return `${date.getFullYear()}${pad(date.getMonth() + 1)}${pad(date.getDate())}`;
  };
  const rid = (prefix, table, column) => {
    let id;
    do {
      id = `${prefix}-${today()}-${crypto.randomBytes(4).toString('hex').toUpperCase()}`;
    } while (db.prepare(`SELECT 1 FROM ${table} WHERE ${column} = ?`).get(id));
    return id;
  };
  const kindOf = (it) => it.item_ID[0] === 'F' ? 'flower'
    : it.item_type === 'กระดาษ' ? 'paper'
    : it.item_type === 'การ์ด' ? 'card' : 'decor';

  function getCartId(req, create) {
    let id = req.session.cartId;
    if (id && db.prepare('SELECT 1 FROM cart WHERE cart_ID=?').get(id)) return id;
    if (!create) return null;
    id = crypto.randomUUID();
    db.prepare('INSERT INTO cart (cart_ID, created_at) VALUES (?,?)').run(id, new Date().toISOString());
    req.session.cartId = id;
    return id;
  }
  function cartCount(req) {
    const id = req.session.cartId;
    if (!id) return 0;
    return db.prepare('SELECT COALESCE(SUM(quantity),0) n FROM cart_items WHERE cart_ID=?').get(id).n;
  }

  function loadCatalog() {
    const items = db.prepare(`SELECT item_ID, item_name, item_type, item_unit_price, quantity_in_stock
                              FROM items ORDER BY item_ID`).all()
      .map((r) => ({ id: r.item_ID, name: r.item_name, type: r.item_type,
                     price: r.item_unit_price, stock: r.quantity_in_stock, kind: kindOf(r) }));
    const tplItems = db.prepare('SELECT template_ID, item_ID, quantity FROM template_items').all();
    const templates = db.prepare('SELECT * FROM bouquet_templates ORDER BY template_ID').all().map((t) => {
      const m = /^(.*?)\s*\(Size ([SML])\)\s*$/.exec(t.template_name);
      const its = {};
      tplItems.filter((x) => x.template_ID === t.template_ID).forEach((x) => (its[x.item_ID] = x.quantity));
      return { id: t.template_ID, base: m ? m[1] : t.template_name, size: m ? m[2] : t.template_ID.slice(-1),
               category: t.template_category, desc: t.description || '', items: its };
    });
    return { items, templates };
  }

  function render(req, res, initial, editId) {
    const { items, templates } = loadCatalog();
    res.render('shop', {
      boot: { items, templates, maxStems: MAX_STEMS, paperQty: PAPER_QTY, decorMax: DECOR_MAX,
              serviceFees: SERVICE_FEES,
              maxQty: MAX_QTY, initial: initial || null, editId: editId || null },
      cartCount: cartCount(req),
    });
  }

  /* ตรวจและคำนวณราคาฝั่ง server เสมอ (ไม่เชื่อราคาจาก browser) */
  function build(body) {
    const size = body.size;
    if (!MAX_STEMS[size]) throw new Error('ขนาดช่อไม่ถูกต้อง');
    const qty = parseInt(body.qty, 10);
    if (!(qty >= 1 && qty <= MAX_QTY)) throw new Error('จำนวนช่อไม่ถูกต้อง');

    const catalog = new Map(db.prepare('SELECT * FROM items').all().map((r) => [r.item_ID, r]));
    const want = new Map();
    for (const x of Array.isArray(body.items) ? body.items : []) {
      const q = parseInt(x.qty, 10);
      if (!catalog.has(x.id) || !(q > 0)) continue;
      want.set(x.id, (want.get(x.id) || 0) + q);
    }

    let stems = 0, papers = 0, cards = 0;
    const perDecor = {};
    const rows = [];
    for (const [id, q0] of want) {
      const it = catalog.get(id), kind = kindOf(it);
      let q = q0;
      if (kind === 'flower') stems += q;
      if (kind === 'paper') { papers++; q = PAPER_QTY[size]; }
      if (kind === 'card')  { cards++;  q = 1; }
      if (kind === 'decor') {
        perDecor[it.item_type] = (perDecor[it.item_type] || 0) + q;
        if (perDecor[it.item_type] > DECOR_MAX[it.item_type]) throw new Error(`เพิ่ม${it.item_type}ได้ไม่เกิน ${DECOR_MAX[it.item_type]} ชิ้น`);
      }
      if (q > it.quantity_in_stock) throw new Error(`${it.item_name} เหลือในสต็อกไม่พอ`);
      rows.push({ item_ID: id, quantity: q, price: it.item_unit_price });
    }
    if (stems < 1) throw new Error('กรุณาเลือกดอกไม้อย่างน้อย 1 ก้าน');
    if (stems > MAX_STEMS[size]) throw new Error(`ช่อขนาด ${size} ใส่ดอกไม้ได้ไม่เกิน ${MAX_STEMS[size]} ก้าน`);
    if (papers !== 1) throw new Error('กรุณาเลือกกระดาษห่อ 1 แบบ');
    if (cards > 1) throw new Error('เลือกการ์ดได้ 1 ใบ');

    const unit = rows.reduce((a, r) => a + r.price * r.quantity, 0);
    const serviceFee = SERVICE_FEES[size];
    const cardMessage = cards ? String(body.cardMessage || '').trim().slice(0, 120) : '';
    const note = String(body.note || '').trim().slice(0, 200);
    const name = String(body.name || '').trim().slice(0, 40);

    // เก็บ template_ID เฉพาะเมื่อรายการตรงกับเทมเพลตทุกอย่าง
    let templateId = null;
    if (body.templateId) {
      const t = db.prepare('SELECT item_ID, quantity FROM template_items WHERE template_ID=?').all(body.templateId);
      const m = new Map(rows.map((r) => [r.item_ID, r.quantity]));
      if (t.length && t.length === rows.length && t.every((x) => m.get(x.item_ID) === x.quantity)) templateId = body.templateId;
    }
    return { size, qty, rows, unit, serviceFee, cardMessage, note, name, templateId };
  }

  const writeItems = (bid, rows) => {
    db.prepare('DELETE FROM bouquet_items WHERE bouquet_ID=?').run(bid);
    const ins = db.prepare('INSERT INTO bouquet_items (bouquet_ID, item_ID, quantity) VALUES (?,?,?)');
    rows.forEach((r) => ins.run(bid, r.item_ID, r.quantity));
  };

  /* ---------- routes ---------- */
  router.get('/', (req, res) => {
    if (req.query.order_id) {
      return res.redirect(`/check-order-status?order_id=${encodeURIComponent(String(req.query.order_id))}`);
    }
    if (['florist', 'counter'].includes(req.query.role)) {
      return res.redirect(`/employee/${req.query.role}`);
    }
    return res.render('customer-home');
  });
  router.get('/shop', (req, res) => render(req, res));

  router.post('/cart/add', (req, res) => {
    try {
      const b = build(req.body);
      const cartId = getCartId(req, true);
      const bid = rid('BQT', 'bouquets', 'bouquet_ID');
      const tx = db.transaction(() => {
        db.prepare(`INSERT INTO bouquets
                    (bouquet_ID, template_ID, bouquet_name, size, service_fee, card_message, note_text)
                    VALUES (?,?,?,?,?,?,?)`)
          .run(bid, b.templateId, b.name || null, b.size, b.serviceFee, b.cardMessage || null, b.note || null);
        writeItems(bid, b.rows);
        db.prepare('INSERT INTO cart_items (cart_ID, bouquet_ID, quantity, price_per_unit) VALUES (?,?,?,?)')
          .run(cartId, bid, b.qty, b.unit);
      });
      tx();
      res.json({ ok: true, redirect: '/cart' });
    } catch (e) { res.status(400).json({ ok: false, error: e.message }); }
  });

  router.get('/bouquet/edit/:id', (req, res) => {
    const cartId = getCartId(req, false);
    const bq = cartId && db.prepare(`SELECT b.*, ci.quantity AS cart_qty FROM bouquets b
                 JOIN cart_items ci ON ci.bouquet_ID=b.bouquet_ID
                 WHERE b.bouquet_ID=? AND ci.cart_ID=?`).get(req.params.id, cartId);
    if (!bq) return res.redirect('/cart');

    const { items, templates } = loadCatalog();
    const byId = Object.fromEntries(items.map((i) => [i.id, i]));
    const initial = { size: bq.size, base: null, flowers: {}, paper: null, decor: {}, card: null,
                      cardMsg: bq.card_message || '', name: bq.bouquet_name || '', note: bq.note_text || '', qty: bq.cart_qty };
    if (bq.template_ID) { const t = templates.find((x) => x.id === bq.template_ID); if (t) initial.base = t.base; }
    db.prepare('SELECT item_ID, quantity FROM bouquet_items WHERE bouquet_ID=?').all(bq.bouquet_ID).forEach((r) => {
      const it = byId[r.item_ID]; if (!it) return;
      if (it.kind === 'flower') initial.flowers[it.id] = r.quantity;
      else if (it.kind === 'paper') initial.paper = it.id;
      else if (it.kind === 'card') initial.card = it.id;
      else initial.decor[it.type] = { id: it.id, qty: r.quantity };
    });
    render(req, res, initial, bq.bouquet_ID);
  });

  router.post('/bouquet/update/:id', (req, res) => {
    try {
      const cartId = getCartId(req, false);
      const own = cartId && db.prepare('SELECT 1 FROM cart_items WHERE cart_ID=? AND bouquet_ID=?').get(cartId, req.params.id);
      if (!own) throw new Error('ไม่พบช่อดอกไม้นี้ในตะกร้า');
      const b = build(req.body);
      db.transaction(() => {
        db.prepare(`UPDATE bouquets SET template_ID=?, bouquet_name=?, size=?, service_fee=?, card_message=?, note_text=? WHERE bouquet_ID=?`)
          .run(b.templateId, b.name || null, b.size, b.serviceFee, b.cardMessage || null, b.note || null, req.params.id);
        writeItems(req.params.id, b.rows);
        db.prepare('UPDATE cart_items SET quantity=?, price_per_unit=? WHERE cart_ID=? AND bouquet_ID=?')
          .run(b.qty, b.unit, cartId, req.params.id);
      })();
      res.json({ ok: true, redirect: '/cart' });
    } catch (e) { res.status(400).json({ ok: false, error: e.message }); }
  });

  return router;
};
````

## 4. โครงสร้างและการจัดการฐานข้อมูล (Database Operations)

### อ่าน catalog และรูปแบบช่อ

````sql
SELECT item_ID, item_name, item_type, item_unit_price, quantity_in_stock
FROM items ORDER BY item_ID;

SELECT template_ID, item_ID, quantity FROM template_items;
````

**ผลของคำสั่ง:** SELECT แรกโหลดวัสดุพร้อมราคา/stock ไปสร้างตัวเลือกใน designer; SELECT ที่สองโหลด BOM ของ template เพื่อประกอบสูตรช่อที่เลือก.


รายงานนี้อธิบายเฉพาะการเรียกฐานข้อมูลจาก source application; ไฟล์ฐานข้อมูลและ schema ภายใน `db/` ไม่ได้คัดลอกลงเอกสาร. ตารางที่ถูกอ้างอิงใน SQL ของระบบรวมถึง `orders`, `order_details`, `payments`, `bouquets`, `bouquet_items`, `bouquet_templates`, `template_items`, `cart`, `cart_items`, `employees` และตารางที่เกี่ยวข้องกับข้อมูลลูกค้า/การจัดส่ง.

- `SELECT`/`JOIN` อ่านคำสั่งซื้อ รายการช่อ payment และพนักงานเพื่อประกอบข้อมูลหน้า dashboard, รายละเอียด, สถานะ และใบเสร็จ.
- `INSERT` สร้าง cart/order/order_details/payment และรายการส่วนประกอบตามขั้นตอนที่ลูกค้ายืนยัน.
- `UPDATE` เปลี่ยนจำนวนสินค้า สถานะงาน สถานะชำระเงิน ผู้จัด และข้อมูลใบเสร็จ; transaction ใช้ครอบการเขียนหลายตารางใน flow ที่ต้องสำเร็จพร้อมกัน.
- `DELETE` เอารายการตะกร้าออก; คำสั่งยกเลิกจะเปลี่ยนสถานะโดยเก็บข้อมูลคำสั่งซื้อไว้.
- ค่าจากผู้ใช้ส่งเป็น SQL parameters ผ่าน prepared statements เพื่อแยกข้อมูลออกจากคำสั่ง SQL.

**ขอบเขตเอกสาร:** อ้างอิงโค้ด `.js`, `.ejs`, `.css` เท่านั้น ไม่รวม `db/`, ฐานข้อมูล, `nnode_modules/`, dependency หรือไฟล์สื่อ. แต่ละ source block เป็น text code fence พร้อมภาษาและ component notes ที่อธิบายหน้าที่/ผลลัพธ์ของส่วนประกอบ.
