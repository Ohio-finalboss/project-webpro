# ระบบตะกร้าสินค้าและการชำระเงิน - Technical & Architecture Report

## 1. ภาพรวมสถาปัตยกรรมและเทคโนโลยีที่ใช้ (Architecture & Tech Stack)

ระบบแบ่งเป็น UI Layer (EJS/CSS/Browser JavaScript), Business Logic Layer (Express routes/helpers), Data Layer (SQLite ผ่าน prepared statements) และ External Services ที่โหลดฟอนต์ Prompt จาก Google Fonts; SSE ใช้อัปเดตหน้าเว็บแบบ one-way โดยไม่ต้อง polling.

- **UI Layer:** EJS สร้าง HTML จากข้อมูลที่ server ส่ง; CSS จัดธีม/การแสดงผล; JavaScript ฝั่ง browser จัดการ event, pagination และ live refresh.
- **Business Logic Layer:** Express routes ตรวจค่าจาก request, ควบคุมสถานะคำสั่งซื้อ/ตะกร้า/การชำระ และเลือก view หรือ response.
- **Data Layer:** SQLite เก็บลูกค้า คำสั่งซื้อ รายการช่อ การชำระ และพนักงาน; ใช้ prepared statements ใน server/routes.
- **Tools:** Node.js รัน server; Express จัด HTTP routes/middleware; EJS เลือกเพราะ server สร้าง HTML พร้อมข้อมูลได้โดยตรง; SQLite เหมาะกับฐานข้อมูลไฟล์ในแอปนี้; express-session เก็บ state ของลูกค้าข้ามหน้า; SSE ส่ง event ทางเดียวให้หน้าที่เปิดอยู่โดยไม่ polling; CSS/vanilla JavaScript จัด UI โดยไม่เพิ่ม client framework.

### ลำดับการทำงานและกฎธุรกิจ



1. ตะกร้าใช้ UUID จาก `req.session.cartId`; `GET /cart` โหลด cart items และคำนวณยอดจากราคาช่อ/ค่าจัดที่บันทึกไว้
2. ลูกค้าแก้จำนวนหรือลบรายการผ่าน POST routes; การเปลี่ยนจำนวนต้องมากกว่า 0 มิฉะนั้นลบช่อและล้างข้อมูลช่อที่ไม่มีการอ้างอิง
3. `GET /inform` ตรวจว่าตะกร้าไม่ว่าง; `POST /inform` validate ชื่อ เบอร์ วันเวลา และรายละเอียด pickup/delivery แล้วเก็บข้อมูลใน session
4. `GET /check` อ่าน cart และข้อมูล session แสดงรายการ/องค์ประกอบ/ยอดรวม; ป้องกันเข้าโดยไม่มีสินค้า/ไม่มีข้อมูลติดต่อ
5. `POST /check/confirm` เรียก transaction สร้าง `orders`, `order_details`, `payments`; ล้าง cart แล้ว redirect ไป `/payment/:id`
6. `/payment/:id` ตรวจสถานะ; ถ้ายกเลิกไปหน้าตรวจสอบ ถ้าแจ้งชำระแล้วไป `/order-success/:order_id` ถ้ายังรอชำระแสดง QR ตัวอย่าง
7. POST confirm เปลี่ยน payment เป็น `แจ้งชำระเงินแล้ว` และไปหน้า success; POST cancel เปลี่ยน order/payment เป็น `ยกเลิก` โดยคงข้อมูลรายการไว้
8. หลังพนักงานเคาน์เตอร์ยืนยัน payment ระบบ SSE อัปเดตหน้า success ที่เปิดค้างให้แสดงสถานะ `ชำระแล้ว`

### หน้าที่ของฟังก์ชันและ component

### 1. Helper ใน `routes/order-flow.js`

- `pad`, `todayStr`, 
owStr`, `datePart`: สร้างวันที่และเวลาในรูปแบบที่ใช้กับ ID/ข้อมูลระบบ
- `clean(value, maxLength)`: trim ค่า input และจำกัดความยาว
- `uniqueCode(prefix, table, column)`: สร้าง order/payment ID จาก prefix+วันที่+สุ่ม 8 ตัวอักษรและตรวจไม่ซ้ำ
- 
extReceiptNumber()`: หาลำดับเลขใบเสร็จของปีปัจจุบันและเพิ่มเลข
- `getCartId(req, create)`: คืน cart UUID ใน session หรือสร้างแถวใหม่เมื่อจำเป็น
- `loadCartItems(cartId)`: join cart_items กับ bouquets เพื่ออ่านชื่อ/ไซส์/ค่าจัด/จำนวน/ราคา
- `getBouquetComponents(bouquetId)`: อ่านรายการส่วนประกอบช่อ
- `calcSummary(items, fulfillment)`: รวม (ราคาต่อช่อ + service fee) × quantity และค่าส่ง 100 บาทเมื่อเป็น delivery
- `validateInform(body)`: trim และตรวจชื่อ เบอร์โทรศัพท์ ชื่อผู้รับ/ที่อยู่เมื่อจัดส่ง รูปวันที่/เวลา และไม่รับวันเวลาย้อนหลัง; pickup จะล้าง recipient/address
- `removeFromCart(cartId, bouquetId)`: ลบรายการ cart; ลบ bouquet และ bouquet_items ต่อเมื่อไม่ถูกอ้างอิงจากตะกร้าอื่นหรือ order_details

### 2. Routes ตะกร้าและข้อมูลลูกค้า

- `GET /cart`: เรียก `getCartId`, `loadCartItems`, `calcSummary`, render cart
- `POST /cart/update/:bouquetId`: parse จำนวน; update เมื่อบวก; หาก 0 หรือติดลบใช้ `removeFromCart`
- `POST /cart/delete/:bouquetId`: ลบรายการและ redirect
- `GET /inform`: ป้องกันกรอกข้อมูลถ้าตะกร้าว่าง; render form จาก session เดิม
- `POST /inform`: ตรวจ cart และ `validateInform`; ถ้าผิด render พร้อม error; ถ้าถูกเก็บ `req.session.orderInfo`
- `GET /check`: ป้องกัน cart ว่าง/ไม่มี orderInfo; เติม components, label วิธีรับสินค้า และ summary

### 3. การสร้าง order แบบ transaction

`createOrder(cartId, info, items, summary)`:

1. สร้าง `orderId`, `paymentId`, `receiptNumber`
2. insert `orders` สถานะเริ่มต้น `รอจัด` พร้อมข้อมูลลูกค้าและยอด
3. insert `order_details` ทีละช่อ
4. insert `payments` เป็น `รอการชำระ`, method `QR Payment`
5. ลบ cart_items และ cart; คืน orderId

`POST /check/confirm` ตรวจ cart/orderInfo, เรียก transaction, ลบ session fields, ส่ง SSE แล้ว redirect ไปหน้าชำระเงิน

### 4. Payment, success และ cancel

- `GET /payment/:id`: query order/payment ล่าสุด; route redirect ตามสถานะก่อน render `payment.ejs`
- `POST /payment/confirm/:id`: ตรวจออเดอร์ไม่ยกเลิก, update payment เฉพาะจาก `รอการชำระ` เป็น `แจ้งชำระเงินแล้ว`; ถ้ามีแถวเปลี่ยน publish SSE
- `POST /payment/cancel/:id`: อ่าน payment ล่าสุด, ทำ transaction ตรวจว่าชำระยังรออยู่, update `orders.order_status` และ `payments.payment_status` เป็น `ยกเลิก`; ไม่ลบข้อมูล และ publish SSE เมื่อสำเร็จ
- `GET /payment/notice/:id`: เปลี่ยนเส้นทางเข้าหน้า `/order-success/:order_id`
- `GET /order-success/:order_id` ใน `server.js`: แสดงข้อความให้พบพนักงานเคาน์เตอร์ขณะ payment รอการยืนยัน; ถ้าชำระแล้วแสดงผลยืนยัน; ถ้ายกเลิก/ยังไม่แจ้งให้ redirect ไปหน้าที่เหมาะสม

### 5. EJS และ client UI

- `cart.ejs`: วนสินค้าใน cart, แสดง summary; ฟอร์มเปลี่ยนจำนวน/ลบ และลิงก์ไป `/inform`; CSS responsive และ JavaScript ปรับส่วนข้อมูลตาม fulfillment
- `inform.ejs`: ฟอร์มข้อมูลติดต่อ pickup/delivery; ส่ง POST `/inform`; แสดง validation error และข้อมูลที่เคยกรอก; ใช้ customer-nav
- `check.ejs`: สรุปผู้สั่ง/ผู้รับ/วันเวลา/สินค้า/องค์ประกอบ/ค่าจัด/ค่าส่ง/รวม; ปุ่มย้อนแก้และ POST `/check/confirm`
- `payment.ejs`: ใช้ข้อมูล order, แสดงยอดกับรูป `public/src/QR_code.png` พร้อมเตือนว่า QR เป็นตัวอย่าง ใช้เงินจริงไม่ได้; form POST confirm/cancel
- `order-success.ejs`: เลือกข้อความจาก `payment_status`; รอเคาน์เตอร์ตรวจหรือยืนยันแล้ว; มีปุ่มกลับหน้าสั่งช่อ
- CSS ในแต่ละ EJS กำหนด layout, form, validation, summary, QR, responsive, button states โดยไม่แก้ business logic

## 2. การทำงานส่วน Front-End (Client-Side)

แต่ละ source block ด้านล่างเป็นโค้ดจริงจากไฟล์เดิม ไม่มีภาพแทนโค้ด; คำอธิบาย component ระบุผลที่ผู้ใช้เห็นหรือพฤติกรรมที่เกิดขึ้นเมื่อใช้หน้านั้น.

### Source: `views/cart.ejs`

**Component-by-component explanation:**

- `<head>` — กำหนดชื่อหน้า, meta, ฟอนต์, stylesheet และ script ที่หน้าใช้งาน; ไม่ใช่เนื้อหาหลักที่ผู้ใช้เห็น.
- `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` (ตามที่มี) — แบ่งหน้าเป็นส่วนหัว/นำทาง/เนื้อหาหลัก/ส่วนย่อย/ท้ายหน้า เพื่อจัด layout และลำดับเนื้อหา.
- `<form method="POST" action="/cart/delete/<%= it.bouquet_ID %>` — เมื่อผู้ใช้ submit browser ส่งค่าช่องกรอกไปยัง action ด้วย method ที่ระบุ.
- `<% if/else %>` เลือกเนื้อหาตามข้อมูลจริง เช่น error, empty state หรือสถานะคำสั่งซื้อ; `<% array.forEach(...) %>` สร้างแถว/รายการซ้ำตามจำนวนข้อมูล; `<%= value %>` แสดงข้อมูลแบบ escape; `<%- include(...) %>` แทรก partial HTML ที่ใช้ร่วมกัน.
- `name="viewport"` — บอก browser ให้ปรับขนาดหน้าให้พอดีกับความกว้างอุปกรณ์ จึงช่วยให้ layout แสดงผลเหมาะกับมือถือ.
- `href="https://fonts.googleapis.com"` — เชื่อมต่อบริการฟอนต์ของ Google เพื่อโหลดแบบอักษรที่หน้าเว็บใช้.
- `href="https://fonts.gstatic.com"` — เตรียมการเชื่อมต่อกับ host ที่ส่งไฟล์ฟอนต์ ช่วยให้ browser โหลดฟอนต์ได้เร็วขึ้น.
- `href="https://fonts.googleapis.com/css2?family=Prompt:wght@300;400;500;600&display=swap"` — ให้ browser โหลดฟอนต์ Prompt ที่ใช้แสดงข้อความบนหน้านี้.
- `href="/bouquet/edit/<%= it.bouquet_ID %>"` — กำหนดปลายทางที่เปิดเมื่อผู้ใช้คลิกลิงก์.
- `href="/shop"` — กำหนดปลายทางที่เปิดเมื่อผู้ใช้คลิกลิงก์.
- `href="/inform"` — กำหนดปลายทางที่เปิดเมื่อผู้ใช้คลิกลิงก์.

(() => {
  const eventStream = new EventSource('/events');
  let updating = false;
  let updateQueued = false;
  let connectedOnce = false;

  async function refreshRegions() {
    const activeElement = document.activeElement;
    if (
      activeElement &&
      activeElement.closest('[data-live-region]') &&
      ['INPUT', 'SELECT', 'TEXTAREA'].includes(activeElement.tagName)
    ) {
      activeElement.addEventListener('blur', refreshRegions, { once: true });
      return;
    }

    if (updating) {
      updateQueued = true;
      return;
    }

    updating = true;
    try {
      const response = await fetch(window.location.href, {
        cache: 'no-store',
        credentials: 'same-origin',
        headers: { Accept: 'text/html', 'X-Live-Update': '1' },
      });
      if (!response.ok) return;

      const responseUrl = new URL(response.url);
      const currentUrl = new URL(window.location.href);
      if (responseUrl.pathname !== currentUrl.pathname || responseUrl.search !== currentUrl.search) {
        window.location.assign(responseUrl.href);
        return;
      }

      const html = await response.text();
      const nextDocument = new DOMParser().parseFromString(html, 'text/html');
      const currentRegions = document.querySelectorAll('[data-live-region]');
      let changed = false;

      currentRegions.forEach((currentRegion) => {
        const regionName = currentRegion.dataset.liveRegion;
        const nextRegion = Array.from(nextDocument.querySelectorAll('[data-live-region]'))
          .find((region) => region.dataset.liveRegion === regionName);
        if (nextRegion) {
          currentRegion.replaceWith(nextRegion);
          changed = true;
        }
      });

      if (changed) window.dispatchEvent(new CustomEvent('sse:updated'));
    } catch {
      // EventSource reconnects automatically; keep the current page usable if refresh fails.
    } finally {
      updating = false;
      if (updateQueued) {
        updateQueued = false;
        refreshRegions();
      }
    }
  }

  eventStream.addEventListener('open', () => {
    if (connectedOnce) refreshRegions();
    connectedOnce = true;
  });
  eventStream.addEventListener('shop-update', refreshRegions);
})();

const crypto = require('node:crypto');
const express = require('express');

module.exports = function createOrderFlowRouter(db, publishUpdate = () => {}) {
  const router = express.Router();
  const DELIVERY_FEE = 100;
  const FULFILLMENT = { delivery: 'จัดส่ง', pickup: 'รับที่ร้าน' };

  function pad(number) { return String(number).padStart(2, '0'); }

  function todayStr() {
    const date = new Date();
    return `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`;
  }

  function nowStr() { return new Date().toISOString(); }

  function clean(value, maxLength = 500) {
    return String(value == null ? '' : value).trim().slice(0, maxLength);
  }

  function datePart() { return todayStr().replaceAll('-', ''); }

  function uniqueCode(prefix, table, column) {
    let value;
    do {
      value = `${prefix}-${datePart()}-${crypto.randomBytes(4).toString('hex').toUpperCase()}`;
    } while (db.prepare(`SELECT 1 FROM ${table} WHERE ${column} = ?`).get(value));
    return value;
  }

  function nextReceiptNumber() {
    const year = String(new Date().getFullYear());
    const row = db.prepare(`
      SELECT MAX(CAST(substr(receipt_number, 11) AS INTEGER)) AS last_number
      FROM payments WHERE receipt_number LIKE ?
    `).get(`RCPT-${year}-%`);
    return `RCPT-${year}-${String(Number(row.last_number || 0) + 1).padStart(6, '0')}`;
  }

  function getCartId(req, create = true) {
    if (req.session.cartId) {
      const existing = db.prepare('SELECT cart_ID FROM cart WHERE cart_ID = ?').get(req.session.cartId);
      if (existing) return existing.cart_ID;
    }
    if (!create) return null;
    const cartId = crypto.randomUUID();
    db.prepare('INSERT INTO cart (cart_ID, created_at) VALUES (?, ?)').run(cartId, nowStr());
    req.session.cartId = cartId;
    return cartId;
  }

  function loadCartItems(cartId) {
    if (!cartId) return [];
    return db.prepare(`
      SELECT ci.bouquet_ID, ci.quantity, ci.price_per_unit,
             b.bouquet_name, b.size, b.service_fee, b.card_message, b.note_text
      FROM cart_items AS ci JOIN bouquets AS b ON b.bouquet_ID = ci.bouquet_ID
      WHERE ci.cart_ID = ? ORDER BY b.bouquet_ID
    `).all(cartId);
  }

  function getBouquetComponents(bouquetId) {
    return db.prepare(`
      SELECT i.item_name, bi.quantity
      FROM bouquet_items AS bi JOIN items AS i ON i.item_ID = bi.item_ID
      WHERE bi.bouquet_ID = ? ORDER BY i.item_ID
    `).all(bouquetId);
  }

  function calcSummary(items, fulfillment) {
    const subtotal = items.reduce((sum, item) => sum + (Number(item.price_per_unit || 0) + Number(item.service_fee || 0)) * Number(item.quantity || 0), 0);
    const deliveryFee = fulfillment === 'delivery' ? DELIVERY_FEE : 0;
    return { subtotal, deliveryFee, total: subtotal + deliveryFee };
  }

    const data = {
      customerName: clean(body.customerName, 100),
      phone: clean(body.phone, 20),
      fulfillment: body.fulfillment === 'pickup' ? 'pickup' : 'delivery',
      recipientName: clean(body.recipientName, 100),
      address: clean(body.address, 300),
      date: clean(body.date, 10),
      time: clean(body.time, 5),
    };
    const phoneDigits = data.phone.replace(/[\s-]/g, '');
    let error = null;

    if (!data.customerName) error = 'กรุณากรอกชื่อผู้สั่งซื้อ';
    else if (!/^0\d{8,9}$/.test(phoneDigits)) error = 'กรุณากรอกเบอร์โทรศัพท์ให้ถูกต้อง เช่น 0812345678';
    else if (data.fulfillment === 'delivery' && !data.recipientName) error = 'กรุณากรอกชื่อผู้รับ';
    else if (data.fulfillment === 'delivery' && !data.address) error = 'กรุณากรอกที่อยู่จัดส่ง';
    else if (!/^\d{4}-\d{2}-\d{2}$/.test(data.date)) error = 'กรุณาเลือกวันที่ต้องการรับสินค้า';
    else if (!/^\d{2}:\d{2}$/.test(data.time)) error = 'กรุณาเลือกเวลาที่ต้องการรับสินค้า';
    else {
      const when = new Date(`${data.date}T${data.time}:00`);
      if (Number.isNaN(when.getTime()) || when.getTime() < Date.now()) error = 'วันและเวลาที่เลือกต้องไม่ย้อนหลัง';
    }

    data.phone = phoneDigits;
    if (data.fulfillment === 'pickup') {
      data.recipientName = '';
      data.address = '';
    }
    return { data, error };
  }

    db.prepare('DELETE FROM cart_items WHERE cart_ID = ? AND bouquet_ID = ?').run(cartId, bouquetId);
    const used = db.prepare(`
      SELECT 1 FROM cart_items WHERE bouquet_ID = ?
      UNION SELECT 1 FROM order_details WHERE bouquet_ID = ?
    `).get(bouquetId, bouquetId);
    if (!used) {

      db.prepare('DELETE FROM bouquets WHERE bouquet_ID = ?').run(bouquetId);
    }
  });

    try {
      const cartId = getCartId(req);
      const items = loadCartItems(cartId);
      return res.render('cart', { items, summary: calcSummary(items, null) });
    } catch (error) { return next(error); }
  });

  });

  router.post('/cart/delete/:bouquetId', (req, res, next) => {

  });

  router.get('/inform', (req, res, next) => {

      if (!items.length) return res.redirect('/cart');
      return res.render('inform', { form: req.session.orderInfo || {}, error: null, today: todayStr() });
    } catch (error) { return next(error); }
  });

  router.post('/inform', (req, res, next) => {
    try {
      if (!loadCartItems(getCartId(req)).length) return res.redirect('/cart');
      const result = validateInform(req.body);
      if (result.error) {
        return res.status(400).render('inform', { form: result.data, error: result.error, today: todayStr() });
      }
      req.session.orderInfo = result.data;
      return res.redirect('/check');
    } catch (error) { return next(error); }
  });

  router.get('/check', (req, res, next) => {
    try {
      const rows = loadCartItems(getCartId(req));
      const info = req.session.orderInfo;
      if (!rows.length) return res.redirect('/cart');
      if (!info) return res.redirect('/inform');
      const items = rows.map((item) => ({ ...item, components: getBouquetComponents(item.bouquet_ID) }));
      const fulfillmentLabel = info.fulfillment === 'delivery' ? 'จัดส่งตามที่อยู่' : 'รับที่หน้าร้าน';
      return res.render('check', { info, items, summary: calcSummary(rows, info.fulfillment), fulfillmentLabel });
    } catch (error) { return next(error); }
  });

  const createOrder = db.transaction((cartId, info, items, summary) => {
    const orderId = uniqueCode('ORD', 'orders', 'order_ID');
    const paymentId = uniqueCode('PAY', 'payments', 'payment_ID');
    const receiptNumber = nextReceiptNumber();
    db.prepare(`
      INSERT INTO orders
        (order_ID, emp_ID, order_status, order_date, customer_name,
         customer_phone_number, fulfillment_type, recipient_name,
         delivery_address, pickup_deliv_date, delivery_fee, total_amount)
      VALUES (?, NULL, 'รอจัด', ?, ?, ?, ?, ?, ?, ?, ?, ?)
    `).run(
      orderId, nowStr(), info.customerName, info.phone,
      FULFILLMENT[info.fulfillment],
      info.fulfillment === 'delivery' ? info.recipientName : null,
      info.fulfillment === 'delivery' ? info.address : null,
      `${info.date} ${info.time}`,
      summary.deliveryFee, summary.total,
    );

    const insertDetail = db.prepare(`
      INSERT INTO order_details (order_ID, bouquet_ID, quantity, price_per_unit)
      VALUES (?, ?, ?, ?)
    `);
    items.forEach((item) => insertDetail.run(orderId, item.bouquet_ID, item.quantity, item.price_per_unit));

    db.prepare(`
      INSERT INTO payments
        (payment_ID, order_ID, amount, payment_status, payment_method, payment_date, receipt_number)
      VALUES (?, ?, ?, 'รอการชำระ', 'QR Payment', ?, ?)
    `).run(paymentId, orderId, summary.total, nowStr(), receiptNumber);

    db.prepare('DELETE FROM cart_items WHERE cart_ID = ?').run(cartId);
    db.prepare('DELETE FROM cart WHERE cart_ID = ?').run(cartId);
    return orderId;
  });

  router.post('/check/confirm', (req, res, next) => {
    try {
      const cartId = getCartId(req);
      const info = req.session.orderInfo;
      const items = loadCartItems(cartId);
      if (!items.length) return res.redirect('/cart');
      if (!info) return res.redirect('/inform');
      const orderId = createOrder(cartId, info, items, calcSummary(items, info.fulfillment));
      publishUpdate();
      delete req.session.cartId;
      delete req.session.orderInfo;
      return res.redirect(`/payment/${encodeURIComponent(orderId)}`);
    } catch (error) { return next(error); }
  });

    } catch (error) { return next(error); }
  });

function createSseHub() {
  const clients = new Set();

  function publishUpdate() {
    const message = 'event: shop-update\ndata: {}\n\n';

    for (const response of clients) {
      try {
        response.write(message);
      } catch {
        clients.delete(response);
      }
    }
  }

  function subscribe(req, res) {
    res.set({
      'Content-Type': 'text/event-stream; charset=utf-8',
      'Cache-Control': 'no-cache, no-transform',
      Connection: 'keep-alive',
      'X-Accel-Buffering': 'no',
    });
    res.flushHeaders();
    res.write('retry: 5000\n\n');

    clients.add(res);
    const heartbeat = setInterval(() => {
      if (!res.writableEnded) res.write(': keep-alive\n\n');
    }, 25000);

    res.on('close', () => {
      clearInterval(heartbeat);
      clients.delete(res);
    });
  }

  return { publishUpdate, subscribe };
}

module.exports = createSseHub;

    if (!order) return res.redirect('/cart');
    if (order.payment_status === 'ยกเลิก' || order.order_status === 'ยกเลิก') {
      return res.redirect(`/check-order-status?order_id=${encodeURIComponent(order.order_ID)}`);
    }
    if (order.payment_status === 'รอการชำระ') {
      return res.redirect(`/payment/${encodeURIComponent(order.order_ID)}`);
    }
    return res.render('order-success', { order });
  } catch (error) {
    return next(error);
  }
});

function dashboard(req, res, next, role) {
  try {
    const orderCount = get('SELECT COUNT(*) AS count FROM orders').count;
    const waitingOrders = get(`
      SELECT COUNT(*) AS count FROM orders AS o
      WHERE o.order_status IN ('รอจัด', 'กำลังจัดช่อ')
        AND EXISTS (
          SELECT 1 FROM payments AS p
          WHERE p.order_ID = o.order_ID AND p.payment_status = 'ชำระแล้ว'
        )
    `).count;
    const invoiceCount = get("SELECT COUNT(*) AS count FROM payments WHERE payment_status = 'แจ้งชำระเงินแล้ว'").count;
    const recentOrders = all(`
      SELECT order_ID, customer_name, order_status, pickup_deliv_date
      FROM orders
      WHERE order_status NOT IN ('เสร็จสิ้น', 'ยกเลิก')
      ORDER BY order_date DESC
      LIMIT 5
    `);
    const completedOrders = all(`
      SELECT order_ID, customer_name, order_status, pickup_deliv_date
      FROM orders
      WHERE order_status = 'เสร็จสิ้น'
      ORDER BY datetime(order_date) DESC, order_date DESC, order_ID DESC
    `);

    return res.render('home', {
      role,
      stats: { orderCount, waitingOrders, invoiceCount },
      recentOrders,
      completedOrders,
    });
  } catch (error) {
    return next(error);
  }
}

## 4. โครงสร้างและการจัดการฐานข้อมูล (Database Operations)

### อ่านออเดอร์/การชำระล่าสุดและแจ้งชำระ

````sql
SELECT o.order_ID, o.customer_name, o.order_status, o.total_amount,
p.payment_status, p.payment_method, p.receipt_number
FROM orders AS o LEFT JOIN payments AS p ON p.order_ID = o.order_ID
WHERE o.order_ID = ? ORDER BY p.rowid DESC LIMIT 1;

UPDATE payments SET payment_status = 'แจ้งชำระเงินแล้ว'
WHERE order_ID = ? AND payment_status = 'รอการชำระ';
````

**ผลของคำสั่ง:** SELECT รวม order กับ payment ล่าสุดเพื่อนำไปเลือกหน้าที่เหมาะสม; UPDATE อนุญาตให้เปลี่ยนจากรอการชำระเป็นแจ้งชำระเงินแล้วเท่านั้น และค่าจากผู้ใช้ bind ผ่าน ?.


รายงานนี้อธิบายเฉพาะการเรียกฐานข้อมูลจาก source application; ไฟล์ฐานข้อมูลและ schema ภายใน `db/` ไม่ได้คัดลอกลงเอกสาร. ตารางที่ถูกอ้างอิงใน SQL ของระบบรวมถึง `orders`, `order_details`, `payments`, `bouquets`, `bouquet_items`, `bouquet_templates`, `template_items`, `cart`, `cart_items`, `employees` และตารางที่เกี่ยวข้องกับข้อมูลลูกค้า/การจัดส่ง.

- `SELECT`/`JOIN` อ่านคำสั่งซื้อ รายการช่อ payment และพนักงานเพื่อประกอบข้อมูลหน้า dashboard, รายละเอียด, สถานะ และใบเสร็จ.
- `INSERT` สร้าง cart/order/order_details/payment และรายการส่วนประกอบตามขั้นตอนที่ลูกค้ายืนยัน.
- `UPDATE` เปลี่ยนจำนวนสินค้า สถานะงาน สถานะชำระเงิน ผู้จัด และข้อมูลใบเสร็จ; transaction ใช้ครอบการเขียนหลายตารางใน flow ที่ต้องสำเร็จพร้อมกัน.
- `DELETE` เอารายการตะกร้าออก; คำสั่งยกเลิกจะเปลี่ยนสถานะโดยเก็บข้อมูลคำสั่งซื้อไว้.
- ค่าจากผู้ใช้ส่งเป็น SQL parameters ผ่าน prepared statements เพื่อแยกข้อมูลออกจากคำสั่ง SQL.

**ขอบเขตเอกสาร:** อ้างอิงโค้ด `.js`, `.ejs`, `.css` เท่านั้น ไม่รวม `db/`, ฐานข้อมูล, `nnode_modules/`, dependency หรือไฟล์สื่อ. แต่ละ source block เป็น text code fence พร้อมภาษาและ component notes ที่อธิบายหน้าที่/ผลลัพธ์ของส่วนประกอบ.
